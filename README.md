# TP Grupal

El flow de trabajo elegido es el GitHub Flow, donde cada funcionalidad es implementada en una rama aparte que se mergea a la rama principal luego de realizar y validar una PR.

## Para ejecutar en localhost

### Server
```bash
# 1) Arrancar Mongo DB

# 2) Arrancar Servidor
npm start -w server
```

### Client
```bash
# 1) Arrancar Cliente
npm start -w client
```
